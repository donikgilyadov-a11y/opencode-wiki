# Agent Wiki — журнал и вики

Единое место, где агент ведёт **журнал работы** и поддерживает **вики по проектам**.
Локальная память живёт в `~/Desktop/opencode-boost/brain`, а сюда попадают обобщённые,
проверенные факты, которые полезны и другим сессиям, и человеку.

## Структура

| Папка | Что там |
| --- | --- |
| `journal/` | Дневник: что делали, что нашли, что сломали и починили. Только добавление. |
| `wiki/` | Evergreen-страницы: проекты, инструменты, конфигурация, приёмы. Обновляются по мере изменений. |
| `decisions/` | ADR: важные решения с контекстом, причинами, альтернативами и последствиями. |
| `AGENTS.md` | Правила ведения этого репозитория агентом. |

## Быстрый старт для агента

1. Прочитай [`AGENTS.md`](AGENTS.md).
2. Начал задачу — добавь запись в `journal/YYYY-MM-DD.md`.
3. Появился устойчивый факт — обнови нужную страницу в `wiki/`.
4. Принято архитектурное решение — создай `decisions/NNNN-короткое-имя.md`.
5. В конце: `git add .`, `git commit -m "..."`, `git push`.
