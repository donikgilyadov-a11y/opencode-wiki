# Повторный аудит ai-os-new

`scripts/reaudit.js` — read-only харнесс, который повторно проверяет 24 результата аудитов
(`P0-1…P0-9`, `P1-1…P1-12`, `P2-1…P2-3`) и сравнивает текущее состояние с базовой линией.
Он нужен, чтобы после исправлений на втором ПК одним запуском понять, что закрылось,
что осталось открытым и где появились новые паттерны.

## Запуск

```powershell
node scripts/reaudit.js "C:\Users\deda donik\Desktop\projects\myproject25112026\ai-os-new-main" --name ai-os-new
```

Полезные флаги: `--json` (только stdout, без сохранения), `--no-save`,
`--refresh-baseline` (перезаписать базу текущим состоянием), `--baseline <путь>`.

Также доступны команда `/reaudit`, навык `reaudit` и npm-скрипт `npm run reaudit -- <папка>`.

## Что происходит

- Строится индекс имён файлов, чтобы проверки переживали переименование папок.
- Для каждой проверки ищутся «открытые» и «исправленные» регулярные выражения; часть проверок
  учитывает близость строк (`window`).
- Значения секретов маскируются.
- Статусы: `open`, `fixed`, `mixed`, `uncertain`, `missing`, `manual`.
- Итог: `brain/reports/ai-os-new-reaudit-YYYY-MM-DD.md` и diff с
  `brain/reports/reaudit-baseline-ai-os-new.json`.
