# Аудит репозиториев

Набор для быстрого понимания чужого или очень большого проекта **без изменений в нём**.

## Инструменты

| Что | Где |
| --- | --- |
| `audit.quick({ directory })` | Плагин `audit-tools`: короткая сводка без записи файла |
| `audit.repo({ directory, name? })` | Полный отчёт в `brain/reports/repo-audit-<имя>-YYYY-MM-DD.md` |
| `node scripts/repo-audit.js <папка> [--json] [--name <имя>] [--no-save]` | CLI-вариант без агента |
| `scripts/audit-core.mjs` | Ядро: `auditRepo`, `renderReport`, `saveReport` |

Навык `repo-audit`, команда `/repo-audit <путь>`. Плагин `~/.config/opencode/plugins/audit-tools/` подхватывается автоматически.

## Что собирает

- Git: ветка, origin, количество изменённых файлов, последний коммит.
- Структуру: количество файлов, размер, расширения, ключевые маркеры (`AGENTS.md`, `README.md`, `package.json`, lockfile, `docs/`, `tests/`, CI).
- `package.json`: имя, версию, скрипты, зависимости.
- `TODO/FIXME/HACK` и похожие маркеры по коду.
- Потенциальные секреты — только **маскированные** совпадения (например, `ghp_****`), без вывода значений.

## Правило безопасности

Аудит **только читает** файлы. Если пользователь поставил границу «не трогать основной репозиторий»,
не выполняйте в нём `install`, `build`, `format`, `commit` или `push` без отдельного явного запроса.
Выводы сохраняйте в `brain/reports/` и через `brain.save`.
