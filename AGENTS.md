# AGENTS — правила ведения репозитория

Эти правила обязательны для агента, который работает с этим репозиторием.

## Язык и стиль

- Пиши по-русски. Код, команды, пути и имена инструментов оставляй как есть.
- Сначала результат, потом детали. Никаких «почти готово»: либо проверено, либо указан блокер.
- Не выдумывай API, поля конфигурации и пути. Сверяйся с `https://opencode.ai/docs/` (только V2).

## Журнал (`journal/`)

- Один файл на день: `YYYY-MM-DD.md`. Формат записи: `- [HH:MM] тема — суть`.
- Журнал **append-only**: старые записи не переписывай, добавляй новые.
- Записывай: что сделано, что discovery, что сломалось и как починил, какие verification прошли.
- Не пиши секреты: токены, пароли, ключи, service password.

## Вики (`wiki/`)

- Страницы — «всегда актуальные»: факт изменился — правишь страницу, а не добавляешь новую.
- Для нового проекта скопируй `wiki/projects/_TEMPLATE.md` в `wiki/projects/<имя>.md`.
- Ссылки между страницами — относительные Markdown-ссылки.
- Если упомянул инструмент/плагин, сверься с реальным состоянием сервиса (`/api/plugin`).

## Решения (`decisions/`)

- Файл `NNNN-короткое-имя.md`, номер — следующий по счёту.
- Обязательные разделы: контекст, решение, причины, альтернативы, последствия.
- Решение не отменяй молча: добавь новое решение со ссылкой на старое.

## Работа с git

- Git не в PATH: используй `C:\Program Files\Git\cmd\git.exe`.
- Локальная identity уже задана: `donikgilyadov-a11y / donikgilyadov-a11y@users.noreply.github.com`.
- Коммит — по смыслу, сообщение на русском, например:
  `Журнал: зафиксирован запуск автопилота`.
- Пушить только после проверки, что файлы записаны в UTF-8 и не содержат мусорных символов.

## Окружение

- PowerShell корёжит UTF-8 в выводе: читать файлы лучше инструментом `read`, а не `Get-Content`.
- npm.ps1 заблокирован политикой: `C:\Program Files\nodejs\npm.cmd`.
- Локальный second brain: `~/Desktop/opencode-boost/brain`; админка: `http://127.0.0.1:8787`.

## Перед завершением

1. Обнови `journal/<дата>.md`.
2. Обнови затронутые страницы `wiki/`.
3. Проверь `git status` и сделай коммит с пушем.
