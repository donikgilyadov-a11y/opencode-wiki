# 0002 — Графы проекта и памяти

- Дата: 2026-11-23
- Статус: принято

## Контекст

Нужно наглядно видеть структуру проекта, импорты/зависимости и связи между заметками второго мозга.
Текстовый поиск не показывает связи между файлами.

## Решение

Сделать общее ядро `scripts/graph-core.mjs` (ESM) и три режима:
`buildProjectGraph`, `buildTreeGraph`, `buildMemoryGraph`. Результат — Mermaid + JSON + Markdown
в `brain/graphs/`. Доступ через плагин `graph-tools`, CLI `graph.js`, команды `/graph-memory`
и `/graph-project`, навык `graph` и страницу `/graph.html` в админке.

## Причины

- Mermaid рендерится прямо в браузере и в Markdown, не требует сервера.
- Единое ядро исключает дублирование логики между CLI и плагином.
- Граф памяти использует уже существующие `[[ссылки]]` и `#теги`.

## Альтернативы

- Внешние сервисы визуализации — лишняя зависимость и утечка данных.
- Ручные диаграммы — быстро устаревают.

## Последствия

- Графы нужно перестраивать после изменений в памяти/структуре.
- Текущий граф памяти: 15 узлов, 41 связь.
