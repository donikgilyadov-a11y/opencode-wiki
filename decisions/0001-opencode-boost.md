# 0001 — Собрать OpenCode Boost

- Дата: 2026-11-23
- Статус: принято

## Контекст

Пользователь поставил цель улучшить OpenCode на компьютере: ставить навыки, инструменты и плагины,
писать рабочие примеры Markdown, сделать вторую админку и второй мозг/память.

## Решение

Создать локальный комплект `~/Desktop/opencode-boost/`: second brain, навыки, команды, агенты,
админку, примеры MD и CLI-скрипты. Подключить его глобально через `opencode.jsonc`
(`instructions`, `skills`, `references`, `permissions`).

## Причины

- Глобальные инструкции загружаются в каждую сессию — память и правила доступны везде.
- Локальные плагины из `~/.config/opencode/plugins/` подхватываются автоматически.
- Админка даёт быстрый обзор сервиса без прямого доступа к API с паролем.

## Альтернативы

- Ничего не менять, работать «как есть» — не даёт памяти и расширений.
- Ставить только готовые плагины из npm — не покрывает локальные задачи (графы, память).

## Последствия

- Появился единый центр конфигурации и памяти; изменения вносятся точечно.
- Нужно поддерживать синхронизацию локального мозга и этой вики.
